# 项目上下文｜拾己 · LIFE

## 1. 项目概览

项目名称：拾己 · LIFE  
英文标识：SHIJI LIFE（暂定）  
世界观：未完成之城  
AI 引路人：微光 Lumi  
产品形态：2D 互动人生探索游戏（Web 优先，桌面端优先适配，同时兼容移动端）  
目标用户：年轻人、大学生，以及处于方向探索阶段的人群。

一句话定位：以模拟人生为外壳，以自我认知为核心，以现实行动为落点。

## 2. 为什么做

许多年轻人有目标困惑、选择困难、想法与行动脱节、关系困惑或对未来不确定等体验。产品希望通过低压力的虚拟生活体验，让玩家先经历，再回顾，再自行理解，而不是直接给一份测评结论。

产品不是心理治疗、诊断或危机干预工具，不承诺治疗焦虑、抑郁等问题，也不替代专业心理服务。

## 3. 核心体验

玩家进入「未完成之城」，可以自由探索六个区域，体验生活事件，与 NPC 建立联系，做出没有绝对对错的选择。游戏记录玩家在授权范围内的经历。微光在合适阶段邀请玩家回顾，提出带证据的观察问题。玩家可以确认、修改或拒绝，逐渐形成个人认知档案，并将部分认识转化为现实行动。

## 4. 已确认产品决策

| 事项 | 已确认内容 |
|---|---|
| 核心玩法 | 自由生活 + 主线剧情 |
| 单轮体验 | 30–60 分钟，完成一段人生体验 |
| 表现形式 | 文字剧情 + 2D 场景 + 互动选择 |
| AI 引路人 | 独立 NPC，可随时交流 |
| 引路人形象 | 金色发光小精灵，名称微光 Lumi |
| 引路人出现 | 在城市中自由活动，玩家可找到，也可主动召唤 |
| 认知反馈 | B：阶段反馈 |
| 反馈原则 | 玩家先生活，系统记录，积累经历后邀请回顾 |
| 认知确认 | 玩家确认后才进入正式认知档案 |

## 5. 世界与区域

「未完成之城」由六个区域构成：
1. 家：私人空间、休息、日记、个人经历。
2. 校园：学习、同伴、能力、比较、未来选择。
3. 街区：社交、关系、表达、边界。
4. 工作室：职业、技能、项目、工作和价值。
5. 公园：休息、独处、情绪观察、日常回顾。
6. 远方：愿景、反愿景、长期方向。

区域可按剧情逐步开放，但不得与心理健康程度或人格评价绑定。

## 6. 角色与 NPC

### 微光 Lumi
- 独立 NPC，不是系统客服、心理医生或宠物。
- 性格：温柔、好奇、耐心、诚实、偶尔俏皮、有边界。
- 能倾听、提问、整理经历和提出观察。
- 不替玩家决定人生，不虚构记忆，不强迫交流。
- 常用表达：「我不能替你决定要去哪里，但我可以陪你，看看前面的路。」

### 校园初始 NPC（建议）
- 林屿：热情同学。
- 沈知夏：安静同学。
- 陈默：目标明确的学生。
- 苏禾：兴趣探索者。
- 周老师：辅导员。

这些角色是初始内容建议，具体人物背景、关系线和台词可在内容制作阶段继续完善。

## 7. 首章设定：初入未完成之城

开场以一间陌生房间、一封没有寄出的信和空白地图引入城市。玩家创建角色，选择当前人生状态和想探索的问题（均可跳过），进入中央广场，认识微光，选择家、校园或公园进行第一次探索，最后开启人生档案。

首章目标不是分析玩家，而是让玩家熟悉城市、角色、自由探索和微光。

## 8. 人生认知循环

人生经历 → 自主选择 → 经历记录 → AI 观察 → 玩家确认/修正 → 认知沉淀 → 现实行动 → 新经历。

四类经历：
- 事件经历
- 人际经历
- 行动经历
- 内心经历

五类认知卡片：
- 我在意什么
- 我经常怎样做
- 我如何思考
- 我想去哪里
- 我准备如何改变

## 9. 六层人生结构（长期成长主线）

1. 反愿景：我不想过怎样的人生。
2. 愿景：我希望过怎样的人生。
3. 一年目标：当前人生主线。
4. 一月项目：阶段挑战。
5. 日常杠杆：每天可执行的小行动。
6. 约束条件：我不愿牺牲的东西。

这六层是长期产品模块，不要求首个可运行版本全部实现。

## 10. 产品体验原则

- 选择没有统一的正确答案。
- 不把选择映射成固定人格标签。
- 情绪不是简单的好/坏分数。
- 精力可以作为游戏资源，但不要用“心理健康值”做评分。
- 允许玩家跳过问题、暂停、拒绝回顾。
- 私人日记默认私密。
- 玩家可查看、修改、删除自己的记忆和认知卡片。
- 不用羞耻、恐惧、损失厌恶或社交比较驱动留存。
- 游戏的价值在于帮助玩家把发现带回现实，而非制造沉迷。

## 11. 当前边界与未知

- 具体视觉素材、角色立绘、地图插画尚需制作或选型。
- 最终数据库部署、模型供应商、鉴权方案和云服务尚未确认。
- 商业化、社区、多人联机、排行榜均不在 MVP 范围。
- 不应将建议阈值（如 5 条经历）解释为心理学标准。
