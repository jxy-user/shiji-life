# 拾己 · LIFE｜Qoder 项目文档入口

> 版本：0.1.0（开发启动基线）  
> 状态：产品方向已确认；技术方案为 MVP 推荐基线，实施前由 Qoder 先做可行性检查，不得擅自改变产品原则。

## 1. 这是什么

《拾己 · LIFE》是一款以模拟人生为外壳、以自我认知为核心、以现实行动为落点的互动人生探索游戏。玩家在一座名为「未完成之城」的 2D 虚拟城市中生活、探索、与 NPC 互动、经历事件并自主选择。游戏记录玩家授权的经历；AI 引路人「微光 Lumi」在阶段节点邀请玩家回顾，提出有证据、可被纠正的观察，帮助玩家形成由本人确认的自我认识，并将其转化为现实中的小行动。

## 3. 当前产品关键决策

- 体验方式：自由生活 + 主线剧情。
- 单轮完整体验：约 30–60 分钟。
- 表现形式：文字剧情 + 2D 场景 + 互动选择。
- 世界：未完成之城，六个区域：家、校园、街区、工作室、公园、远方。
- AI 引路人：微光 Lumi，金色小精灵；在城市中活动，玩家可以找到它，也可以主动召唤。
- AI 认知反馈：**阶段反馈 B**。玩家先正常生活，系统记录授权经历；积累足够材料或到达剧情节点后，微光才邀请回顾。玩家可接受、推迟、拒绝。
- AI 观察是候选假设，不是诊断；只有玩家确认的内容进入正式认知档案。
- 产品不是心理治疗工具，不做人格诊断，不给玩家贴标签。

## 4. 重要说明

这套文档是从产品讨论中整理出的开发基线，不代表代码已经存在。若仓库已有实现，先检查代码和依赖，再提出差异清单；不要为了符合文档而无条件重写已有可用代码。

对于未确认的技术细节，标记为“建议/待确认”，先采用最小、可验证的实现。不要自行增加社交、付费、排行榜、复杂经济系统或实时多人功能。

## 5. 如何开始

先把本目录中的文件复制到项目根目录，保持 `AGENTS.md` 位于根目录、`docs/` 位于根目录。然后在 Qoder 中打开该项目文件夹。

第一次给 Qoder 的任务请使用 `docs/QODER_FIRST_PROMPT.md`。第一阶段只要求它阅读、检查、提出实施计划，不要立即生成大量业务代码。
