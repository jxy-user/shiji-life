# 项目背景与已确认决策（PROJECT_CONTEXT）

> 更新于 2026-11-25。旧版城市模式已移除，本文只记录当前形态与仍然有效的决策。

## 1. 项目背景

《拾己 · LIFE》参加 Qoder 大赛，同时投向两个方向：与「互动叙事」相关的赛道，以及与「年轻人方向探索」相关的赛道（同一作品，两套作品帖包装）。

外部约束优先于任何技术建议：

- 必须部署到 **Qoder Sites** 公网链接，评委点开即玩。
- 「打开就能用、不需要说明书」「能在浏览器里玩 3 分钟」→ 不做账号登录、不使用后端。
- 「技术复杂度不计分」→ 砍掉后端，做小而顺。
- Qoder 使用深度是评分项之一：作品帖里 Qoder 的部分必须写实。

## 2. 当前定位

一款以「人生抉择」为核心的网页互动叙事游戏：18 → 60 岁，11 个重大抉择，最后回放这一生。

- 单局约 3–8 分钟。
- 无登录、无后端、可离线（PWA 渐进式网页应用）。
- 所有数据只保存在本设备。

## 3. 已确认决策

| 决策 | 原因 |
|---|---|
| 使用 **HashRouter**（哈希路由，如 `/#/life`） | Qoder Sites 为静态托管，没有 SPA（单页应用）回退，直接访问 `/life` 会 404 |
| 不做真实 AI，不做服务端 | Qoder Sites 免费计划仅静态托管；真实 AI 需要服务端与密钥 |
| 只保留一条人生线，删除旧版城市模式 | 用户要求简化：「对准一条故事线即可」；旧版城市代码已于 2026-11-25 删除 |
| 存档只放 `localStorage` | 无后端；`shiji-life:life:v1` |
| 音效用 Web Audio 现场合成 | 不加载音频文件，无版权与体积问题 |
| 仅桌面端（`viewport width=1280`） | 用户明确「只保留电脑端」 |
| 不做 Electron / Tauri 打包 | 静态托管与浏览器游玩是硬约束 |

## 4. 产品原则

1. 不诊断、不评判、不贴标签，不给选择打分。
2. 选择前不透露结果或归类；倾向统计只在最终回放出现。
3. 结局只回放事实，明写「这不是评判」。
4. 不使用羞耻、恐惧、损失厌恶、连续天数等压力机制。
5. 不做社交、排行榜、付费、经济系统、多人在线。
6. 玩家可以随时重新开始或清除本地数据。

## 5. 技术约束

- 构建：Vite + React + TypeScript + Tailwind。
- 路由：React Router（HashRouter）。
- 状态：Zustand（`useLifeStore`）。
- 校验：已移除 zod（旧版存档校验随旧版删除）。
- PWA：`vite-plugin-pwa`，离线缓存 + 更新提示。
- 音效：Web Audio API 合成，首次交互后解锁。

## 6. 已知限制

- 内容量固定：11 个节点、每个 3 个选项。
- 3D 门厅方案已被否决（只能看到一个门、丢失远景），门厅使用 SVG 绘制。
- 旧路径（`/#/city` 等）会回到门厅并提示一句。
- 回放时长约 1 分钟（每条 6 秒），可跳过。
