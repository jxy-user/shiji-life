# 产品需求文档（PRODUCT_PRD）

> 更新于 2026-11-25。本文只描述当前主线：门厅 → 人生线 → 回放。
> 旧版城市模式（城市/档案/行动/日记/设置等）已移除，不在本文范围内。

## 1. 产品定位

《拾己 · LIFE》是一款以「人生抉择」为核心的网页互动叙事游戏。玩家从 18 岁走到 60 岁，经历 11 个重大抉择，每选一项推进一段剧情，最后以回放动画呈现所有选择与倾向关键词。

**一句话**：用几分钟，把一生的几个岔路口走一遍，然后回看自己选了什么。

**目标玩家**：18–35 岁、对人生方向有困惑或好奇的年轻人；比赛评委；愿意在一杯咖啡时间里体验一段叙事的普通玩家。

**使用场景**：桌面浏览器打开即玩，无需登录、无需说明书，单局约 3–8 分钟。

## 2. 核心体验

### 2.1 门厅

- 打开页面，镜头由远及近走向一座旧城门。
- 标题「拾己」与「轻触门扉」渐显；门缝透出暖光，照亮门前地面。
- 推门后播放白幕字幕（三句），随即进入人生线。
- 已有进度时，门厅显示当前年龄；已走完则直接进入回放。

### 2.2 人生线 18 → 60

- 11 个年龄节点：18、22、25、28、32、36、40、45、50、55、60。
- 每个节点：一句场景、一个抉择、3 个选项。
- 呈现方式为「播放」：标题卡（年龄/幕次）→ 场景逐字 → 问题逐字 → 选项浮现。
- 选择后播放一段结果，再出现「继续」。
- 玩家看不到任何结果预告或倾向标签。

### 2.3 回放

- 逐条播放所有选择（年龄、节点、选择、结果）。
- 左侧时间轴随进度点亮，顶部进度条增长。
- 结尾显示「这一生的关键词」与倾向标签，并明写「这不是评判」。
- 可随时跳过；可重新开始。

## 3. 页面与路由

| 路由 | 页面 | 职责 |
|---|---|---|
| `/#/` | 门厅 | 镜头、推门、白幕字幕、清除本地数据 |
| `/#/life` | 人生线 | 节点抉择与结果 |
| `/#/life/replay` | 回放 | 逐条播放与关键词 |

旧路径（如 `/#/city`、`/#/archive`）已移除，访问时回到门厅并提示一句「这个地址已经不存在了」。

## 4. 内容结构

- 11 个节点，每个 3 个选项。
- 每个选项带 1 个倾向标签：向外走 / 守住 / 靠近人 / 回到自己 / 交出去。
- 标签只用于最终统计，不对玩家展示单个选择的标签。
- 内容细节见 `docs/GAMEPLAY_AND_STORY.md`。

## 5. 产品原则（红线）

1. **不诊断、不评判、不贴标签**：不给选择打分，不说「你应该」。
2. **未知感**：选择前不透露结果、后果或归类；结果页也不显示倾向标签。
3. **选择没有对错**：每个选项都是不同，不是好坏。
4. **结局只回放事实**：统计倾向并明写「这不是评判」。
5. **不制造压力**：不使用羞耻、恐惧、损失厌恶、连续天数、打卡等机制。
6. **不做社交与商业化**：无排行榜、无付费、无经济系统、无多人在线。

## 6. 数据与隐私

- 只使用浏览器 `localStorage` 保存人生进度与音效偏好，无后端、无上传。
- 存档键：`shiji-life:life:v1`；音效偏好：`shiji-life:sound-muted`。
- 门厅页脚提供「清除本地数据」，确认后清空人生进度、旧版存档与音效偏好。
- 不收集任何个人信息。

## 7. 验收标准

1. 打开 `/#/` 能看到门厅与「轻触门扉」，无需登录。
2. 推门后播放白幕字幕并进入人生线。
3. 每个节点按「标题卡 → 场景 → 问题 → 选项」播放；动画期间选项不可点。
4. 选择后播放结果，出现「继续」；刷新页面后仍能看到刚才的结果。
5. 走完 60 岁进入回放，逐条播放并在结尾给出关键词。
6. 回放可跳过；「再走一次」从 18 岁重新开始。
7. 门厅「清除本地数据」会清空全部本地数据并刷新。
8. 旧路径访问回到门厅并给出提示。
9. 开启减少动态效果时，动画直接到终态，不阻塞操作。
10. `npm run typecheck && npm run lint && npm test && npm run build` 全部通过。

## 8. 非目标

- 不做多人在线、社交、排行榜、付费、经济系统。
- 不做心理测评、人格测试或诊断报告。
- 不做账号体系、云同步、服务端存储。
- 不做移动端专门布局（当前仅桌面端）。
- 不做 Electron / Tauri 桌面打包。
