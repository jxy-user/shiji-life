## 任务正文

### 背景

M1（首章可玩）已完成并提交。本轮职责是**验证、审查、部署**，不是重写。

开始前请先同步代码（`git pull`），然后阅读：

1. `AGENTS.md`（产品不可破坏原则、工程原则、AI 约束）
2. `README.md`（命令、目录、路由说明）
3. `docs/ROADMAP_AND_ACCEPTANCE.md` 中 M1 的状态记录
4. `docs/AI_REFLECTION_SYSTEM.md` 第 5 节（信息可信度分类）——本轮 UI 文案不应出现任何人格判断

上一轮遗留：`.deploy-m0/` 是部署 M0 用的独立工作树，里面有自己的 `node_modules`。主仓库的 `vitest.config.ts` 已把它排除，若它不再需要，请清理以免占用磁盘；**清理前先确认它没有未推送的内容**。

### 二、功能验收（逐条点，不通过就记录）

用浏览器（含 390px 手机视口）走一遍：

1. 首页 → 「开始新的旅程」→ 开场五幕，第三幕选「把信读完」，其余「继续」，最后「推开门」。
2. 角色页：改昵称、选形象、选一个人生状态，点「推门，进入城市」。
3. 城市页：点老树旁的微光 → 三选一 → 对话结束；再点微光应变为简短应答。
4. 进入公园 → 做任意一个行动 → 精力与时段发生变化 → 「回到城市」。
5. 回到城市应出现「第一章 · 完成」卡片，并自动滚入视野；点「打开人生档案」应进入占位页。
6. **刷新页面 → 从首页点「继续旅程」应回到城市，昵称、天数、精力、访问过的区域都保留。**
7. 直接访问 `/#/archive`、`/#/scene/park` 应能正常打开（不应 404）。

### 二·五、复核上一轮审查意见的落地情况

上一轮的五条建议已全部处理，请逐条验证，确认真的生效（而不是只确认代码改了）：

1. `DialoguePanel.tsx`：焦点 effect 依赖改为 `[nodeId]`。验收方式：只用 Tab 键操作，选完一个选项后，焦点应回到对话面板，而不是掉到页面顶部。
2. `ScenePage.tsx`：`aria-live` 容器常驻、只条件渲染内部结果框，并加 `aria-atomic`。验收方式：检查 DOM 结构；若能用读屏软件，确认行动结果会被朗读。
3. 焦点环：改为 `gold-600`，**未采用 ink-900**——开场背景是深色（`#211d19`），深色环在那里几乎不可见。请在开场页（深底）和城市页（浅底）各按一次 Tab，确认两种背景上都能看见。
4. 小字对比度：五个文件里的 `ink-400` 已改 `ink-500`。请抽查城市地图标签、场景行动提示、建角页「可跳过」。
5. `saveService.ts`：新增 `readVersion()` 闸门与 `migrateSave()` 占位。请确认版本号缺失/非数字的存档被判为无存档，且**原始数据没有被覆盖或清除**。

### 二·六、本轮遗留问题的处理（请复核）

1. `updateProfile` 现在返回真实写盘结果（`commit()` 的返回值），不再恒为 true。
2. 写盘失败会在所有页面底部显示提示条（`PersistenceNotice`），文案明确「刷新后会丢失」；该状态只在真正写成功后才清除，读一次页面不会抹掉警告。
3. 删除了未使用的 `REST_ENERGY`。
4. `story.ts`「路过」分支改为 `我常常待在路边，看人和车经过。`——把描述对象从玩家换成微光自己，去掉隐含评价。
5. 新增页面流程测试 `src/pages/flow.test.tsx`：首页 → 开场五幕（含一次选择）→ 建角 → 城市，并断言存档写入；另有一条「跳过开场」用例。
6. 通关卡关闭状态改存为存档标记 `chapterCardDismissed`，刷新后不再重复出现；自动滚动也会跳过已关闭的情况。

验收方式：关掉浏览器的 localStorage（或用隐私模式）走一遍流程，应看到底部提示条且游戏不中断；正常模式通关后点「继续在城里走走」，刷新页面不应再弹出通关卡。

### 三、代码审查（只报告，不擅自改）

重点：

- `src/game/saveSchema.ts`：Zod 校验是否完备；`version` 字段与迁移策略是否留好了口子；坏存档是否被安全忽略而**不覆盖**原始数据。
- `src/services/saveService.ts`：JSON 解析失败、schema 失败、写入失败（隐私模式）三条路径的行为。
- `src/stores/useGameStore.ts`：是否所有状态变化都经过 action；精力是否钳制在 0–100；AI 是否**没有**任何写入口。

- 测试有效性：14 个用例是否真的在验证行为，有没有空断言。
