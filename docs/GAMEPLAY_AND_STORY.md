# 玩法与剧情（GAMEPLAY_AND_STORY）

> 更新于 2026-11-25。当前主线为「18 → 60 岁的重大抉择」，旧版城市探索玩法已移除。

## 1. 主线结构

```
18 岁 志愿表
22 岁 第一份工作
25 岁 升职与离开
28 岁 一起生活
32 岁 一套房
36 岁 一个机会
40 岁 父母的电话
45 岁 身体的提醒
50 岁 交接
55 岁 一个年轻人的问题
60 岁 退休那天
```

每个节点包含：一句场景、一个抉择、3 个选项；选择后播放一段结果。

## 2. 节点与选项

| 年龄 | 节点 | 选项（中性描述） |
|---|---|---|
| 18 | 志愿表 | 选有前途的专业 / 选自己好奇的方向 / 选离家近的学校 |
| 22 | 第一份工作 | 去大城市 / 回小城 / 留在读书的城市 |
| 25 | 升职与离开 | 接下升职 / 辞职换行业 / 留在原位 |
| 28 | 一起生活 | 搬过去 / 保持距离 / 说还没准备好 |
| 32 | 一套房 | 贷款买下 / 继续租 / 回老家买 |
| 36 | 一个机会 | 全力拼一次 / 不冒险 / 分一半精力试试 |
| 40 | 父母的电话 | 接到身边 / 定期回去 / 请人照顾 |
| 45 | 身体的提醒 | 停下来 / 先扛过项目 / 换更慢的活法 |
| 50 | 交接 | 交给年轻人 / 守住位置 / 学新东西 |
| 55 | 一个年轻人的问题 | 告诉他经验 / 让他自己决定 / 说「我也还在找」 |

完整文案与结果在 `src/data/lifeStory.ts`。

## 3. 选项设计原则

1. **没有对错**：三个选项只是不同，不设「正确答案」。
2. **不评价**：结果只写「发生了什么」，不写「你做对了/错了」。
3. **不预言**：结果不预告后续人生，留白给玩家。
4. **标签隐藏**：每个选项内部带一个倾向标签（向外走 / 守住 / 靠近人 / 回到自己 / 交出去），但玩家在选择前与结果页都看不到标签；只为最终回放统计服务。
5. **措辞克制**：不使用「应该」「必须」「成功/失败」等施压词。

## 4. 倾向统计与回放

- 每个选择记录一个倾向标签。
- 走完 11 个节点后，统计出现最多的倾向，作为「这一生的关键词」。
- 平票时显示「几种都有一点」，不强行选一个。
- 回放逐条播放所有选择，结尾明写「这不是评判，只是你走过的一条路」。

## 5. 门厅叙事

- 门厅是「旧城门」：镜头由远及近，门缝透出暖光，推门进入。
- 白幕字幕三句：
  1. 先生活，再认识自己。
  2. 在这座还没建完的城市里，选择没有标准答案。
  3. 你经历的每件小事，都会在某个时刻被温柔地回望。
- 「未完成之城」是世界观背景，不再对应可探索的城市地图。

## 6. 内容扩充指引

新增一个节点时：

1. 在 `src/data/lifeStory.ts` 的 `LIFE_NODES` 中追加（保持年龄递增）。
2. 在 `src/components/life/LifeGlyph.tsx` 的 `GLYPHS` 中补对应图标（缺失会回退到 18 岁图标）。
3. 为 3 个选项各写一段结果，并各带 1 个倾向标签。
4. 控制总节点数在 12–14 个以内，保证回放节奏。

## 7. 原则（不可违反）

- 不诊断、不评判、不贴标签。
- 选择前不透露结果或归类。
- 结局只回放事实，不制造羞耻或恐惧。
- 玩家可以随时「重新开始」或「清除本地数据」。
