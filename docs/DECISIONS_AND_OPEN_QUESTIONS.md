## 2. 建议但尚未最终确认

- 技术栈采用 React + TypeScript + Vite、Tailwind、PostgreSQL、Prisma。
- MVP 场景采用静态 2D 背景图 + DOM 热区，不使用完整游戏引擎。
- 阶段回顾默认阈值为 5 条有效经历、至少 2 类经历。
- 首章先做中央广场、校园、家、公园。
- 第一版先 mock AI，再接真实模型。

## 3. 待确认事项

1. 是否需要账号登录？建议原型阶段先本地单用户存档。
2. 正式部署目标和云服务供应商是什么？
3. 最终模型供应商和预算是什么？
4. 是否需要音效、背景音乐和配音？首版可先不做。
5. 角色形象和场景素材由 AI 生成、购买还是自行绘制？
6. 是否要支持手机竖屏？建议先桌面优先、移动端适配。
7. 正式上线前的数据保留、隐私政策和用户数据导出方案。

## 4. 冲突处理

- 已确认产品原则优先于 AI 自行推断。
- 新需求与已确认原则冲突时，先向用户说明冲突。
- 技术实现与产品体验冲突时，先提出取舍，不要擅自改变产品。
- 如果实现成本过高，先给出 MVP 简化方案。
- 文档未说明的事项应标记为待确认，不得伪装成已决定。
