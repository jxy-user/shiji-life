# 开发路线图与验收标准｜拾己 · LIFE

## 1. 开发策略

采用垂直切片：先完成一段从进入游戏到保存经历的真实可玩流程，再加入阶段回顾。不要先铺开所有地图、NPC 和 AI 能力。

## 2. 里程碑

### M0：项目骨架
- 检查现有仓库、技术栈和运行方式。
- 建立路由、全局样式、基础布局。
- 建立文档、代码规范和测试脚本。
- 验收：项目可安装、启动、构建。

**状态：已完成（2026-11-20）**

- 技术栈：Vite 8 + React 19 + TypeScript 7 + Tailwind CSS 4 + React Router 7 + Zustand 5 + Vitest 5（oxlint 做静态检查）。
- 已建立：设计令牌（`src/index.css`）、路由表（`src/app/App.tsx`）、开始页、七个占位页、localStorage 存档探测（`src/services/storage.ts`）、领域类型（`src/types/game.ts`）。
- 已验证：`npm run typecheck`、`npm run lint`、`npm test`（6 项）、`npm run build` 全部通过；桌面与 390px 移动视口渲染正常。
- 尚未建立：事件 JSON schema、游戏引擎 reducer、AI 适配层（分别属于 M2、M4）。

### M1：首章可玩
- 开场剧情。
- 角色创建。
- 城市首页。
- 中央广场、家、校园、公园入口。
- 微光首次登场和基础对话。
- 首次探索。
- 本地存档。
- 验收：新玩家完整走完第一章，刷新可恢复。

**状态：已完成（2026-11-20）**

- 开场五幕（雨、房间、信、地图、门），第三幕有一次语气选择，可整体跳过。
- 角色创建：昵称、四款 SVG 形象、人生状态与探索问题（均可跳过）。
- 城市首页：七个热区（四个可进入，三个显示建造中），状态栏显示天数、时段与精力。
- 微光首次见面为脚本对话，三选一开场后汇合；认识后可再次呼唤，只做简短回应，不做任何分析。
- 四个区域各 3 个行动，行动有精力变化与时段推进，结果文案只描述发生的事。
- 第 1 章完成卡会出现一次，并自动滚入视野，提供「打开人生档案」（占位）入口。
- 存档：`src/game/saveSchema.ts`（Zod 校验、版本号 v1）+ `src/services/saveService.ts`（损坏保护）；刷新可恢复。
- 路由改为 HashRouter：实测 Qoder Sites 静态托管对 `/archive`、`/city` 返回 404，没有 SPA 回退。
- 已验证：`typecheck`、`lint`、`test`（14 项）、`build` 通过；无头 Chrome 完整跑通「首页 → 开场 → 建角 → 城市 → 公园 → 行动 → 返回 → 通关卡 → 刷新恢复」。
- 未包含：事件系统与经历记录（M2）、阶段回顾（M3）。

### M2：事件和经历
- 事件 JSON schema。
- 事件剧情页面。
- 选择、结果、有限分支。
- 经历记录和授权设置。
- 验收：不同选择产生正确结果；经历记录可查、可删除。

### M3：阶段回顾（先 mock）
- 阈值判断。
- 回顾邀请、接受、稍后、拒绝。
- 经历回顾时间线。
- mock 观察结果。
- 确认、修改、拒绝观察。
- 认知档案。
- 验收：完整跑通经历 → 候选观察 → 玩家确认 → 认知卡片。

### M4：接入真实 AI
- 服务端模型适配层。
- Prompt 版本管理。
- JSON schema 校验。
- evidence ID 校验。
- 超时、失败和无观察降级。
- 验收：AI 不可用时游戏仍可玩；AI 不得越权写入正式档案。

### M5：现实行动与阶段总结
- 现实行动创建和状态。
- 行动复盘。
- 人生档案阶段总结。
- 验收：玩家可将认知转成行动，并记录结果。

## 4. MVP 验收清单

### 游戏
- [ ] 新玩家可完成首章。
- [ ] 角色创建字段可选且可跳过。
- [ ] 城市区域入口可用。
- [ ] 事件选择和分支正确。
- [ ] 刷新后恢复存档。
- [ ] AI 服务失败不阻断游戏。

### 经历与回顾
- [ ] 有效经历被正确保存。
- [ ] 撤回授权的经历不会进入后续分析。
- [ ] 达到阈值才触发邀请。
- [ ] 邀请支持接受、稍后、拒绝。
- [ ] 拒绝后不会立即反复邀请。
- [ ] 展示观察对应的经历证据。
- [ ] 证据不足时不生成观察。
- [ ] 玩家确认前不写入正式认知档案。
- [ ] 玩家可修改、拒绝和删除认知卡片。

### 隐私与安全
- [ ] 私人日记默认不用于 AI 分析。
- [ ] AI Key 仅在服务端。
- [ ] API 按用户隔离数据。
- [ ] LLM 输出经过 schema 校验。
- [ ] 不存在跨用户读取。
- [ ] 删除/撤回授权后，后续分析不再使用相关内容。

### 工程
- [ ] typecheck 通过。
- [ ] lint 通过（若配置）。
- [ ] 单元测试通过。
- [ ] build 通过。
- [ ] README 含启动说明和环境变量说明。
- [ ] 数据库迁移可从空库执行（接入数据库后）。

## 5. 每个里程碑的交付格式

- 完成内容
- 修改文件
- 运行方式
- 验收命令及结果
- 未完成项
- 风险和待确认事项
