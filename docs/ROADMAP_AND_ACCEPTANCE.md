## 2. 验收标准

### 门厅

1. 打开 `/#/` 能看到城门、「拾己」标题与「轻触门扉」。
2. 门厅自动播放镜头推近；「跳过」可直接抵达。
3. 推门后播放三句白幕字幕，播完进入人生线；点击白幕可跳过字幕。
4. 有进度时门厅显示当前年龄；已走完则推门进入回放。
5. 门厅页脚「清除本地数据」确认后清空人生进度、旧版存档与音效偏好，并刷新。

### 人生线

6. 每个节点按「标题卡（约 1.4 秒）→ 场景逐字 → 问题逐字 → 选项浮现」播放。
7. 动画期间选项不可点击（键盘也无法聚焦）；可点「跳过动画」直达终态。
8. 选择后播放结果（逐字），再出现「继续」。
9. 刷新页面后仍能看到刚才的选择结果（`pendingChoice` 持久化）。
10. 走完 11 个节点后自动进入回放。
11. 玩家在选择前与结果页都看不到倾向标签。

### 回放

12. 逐条播放所有选择；可「跳过回放」。
13. 结尾显示「这一生的关键词」；平票显示「几种都有一点」。
14. 明写「这不是评判」；提供「再走一次」与「回到首页」。

### 通用

15. 旧路径（`/#/city`、`/#/archive` 等）回到门厅，并提示「这个地址已经不存在了」。
16. 开启减少动态效果（prefers-reduced-motion）时，动画直接到终态，不阻塞操作。
17. 音效开关状态在刷新后保留；关闭后全部音效静默。
18. `npm run typecheck && npm run lint && npm test && npm run build` 全部通过。

## 3. 后续可做

1. **内容扩充**：新增 1–3 个节点（12–14 个），同步补图标。
2. **部署验证**：Qoder 拉取最新提交、重新构建部署；用全新浏览器与已安装态各验一次。
3. **可选真实 AI**（赛后）：若 Qoder Sites 升级支持服务端，可接入真实模型生成回放文案。

## 4. 非目标

- 不做多人在线、社交、排行榜、付费、经济系统。
- 不做心理测评、人格测试或诊断。
- 不做移动端专门布局；不做 Electron / Tauri 打包。
- 不重新引入 3D 引擎（Three.js 方案已被否决）。
