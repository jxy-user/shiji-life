# Qoder 开发任务模板

每次让 Qoder 开发一个功能时，复制此模板并填写：

## 任务目标
[一句话描述本次要完成的功能]

## 背景
请先阅读：
- `AGENTS.md`
- `docs/PROJECT_CONTEXT.md`
- [本任务对应 PRD 文档]
- [相关代码目录/文件]

## 本次范围
- [本次必须实现的内容]

## 不在本次范围
- [明确不做的内容]

## 产品规则
- 遵循 AGENTS.md 的产品不可破坏原则。
- 不得擅自新增产品功能或改变已确认决策。
- AI 观察必须有证据，玩家确认前不能进入正式认知档案。

## 实施要求
1. 先检查现有实现。
2. 先给出计划和拟修改文件。
3. 小步实现，不做无关重构。
4. 补充必要测试和文档。
5. 运行项目实际配置的验证命令。

## 验收标准
- [可观察、可验证的条件 1]
- [可观察、可验证的条件 2]
- [错误/边界情况]

## 最终汇报
列出实现内容、修改文件、测试命令及真实结果、未完成项和风险。
