# AI 人生回响系统｜阶段反馈设计

> **状态：已移除（2026-11-25）**。本系统对应的城市生活、经历记录、阶段回顾、认知档案等模块已随旧版城市模式删除，当前游戏不再运行任何 AI 观察或回顾流程。
>
> 本文保留作设计原则参考（不诊断、不贴标签、观察需证据、玩家确认后才入档），不再与代码同步。

## 1. 产品决策

采用 B 方案：阶段反馈。

玩家正常生活，系统在授权范围内记录经历；积累足够材料或到达剧情节点后，微光邀请玩家回顾。不是每次选择后即时分析。

核心原则：玩家负责生活，游戏负责记录，微光负责观察，玩家负责认识自己。

## 2. 五阶段流程

1. 自由体验：玩家探索、参与事件、与 NPC 交流。
2. 经历积累：记录选择、结果和玩家主动表达。
3. 发现线索：系统寻找可能值得回顾的重复现象或变化。
4. 微光邀请：玩家可接受、推迟、拒绝。
5. 认知沉淀：玩家确认、修改或拒绝观察；确认内容进入档案。

若证据不足，系统不生成观察，也不为了触发而硬凑结论。

## 3. 触发机制

建议 MVP 默认值：
- 至少 5 条有效经历。
- 至少覆盖 2 类经历。
- 或完成章节节点时允许回顾。
- 重要表达/变化可进入候选触发队列，但不能仅凭单次行为判断人格。

频率控制：
- 每游戏日普通邀请最多一次。
- 深度回顾设置冷却时间，默认至少间隔一个游戏日。
- 玩家拒绝后不立即重复邀请。
- 玩家选择稍后，在自然节点再次询问。
- 玩家关闭阶段反馈后，只记录经历，不主动邀请。

这些是产品配置值，不是心理学标准。

## 4. 经历类型

- event：事件经历
- social：人际经历
- action：行动经历
- inner：内心经历

每条经历至少包含来源、时间、场景、玩家选择、结果、授权状态。玩家理由和感受是可选字段，必须由玩家主动表达。

## 5. 信息可信度分类

- explicit：玩家明确表达。
- behavior：客观行为记录。
- observation：AI 观察。
- hypothesis：待确认假设。

禁止把 observation 或 hypothesis 写成 explicit。玩家确认后的内容才可成为正式 self insight。

## 6. 回顾交互

1. 微光邀请：「最近我们一起经历了不少事情。我有一些小发现，但不确定是不是我理解的那样。你愿意聊聊吗？」
2. 玩家选择接受、稍后或拒绝。
3. 展示被授权的代表性经历，允许玩家排除某条经历。
4. 微光提出一个观察，并展示证据。
5. 玩家可确认、纠正、否认、不确定或暂不讨论。
6. 微光根据玩家回应追问一个问题，优先倾听。
7. 生成认知卡片草稿。
8. 玩家确认、修改、暂不保存或删除。
9. 只有确认后进入正式档案。

## 7. 回顾场景包装

- 公园：日常轻回顾。
- 家：私人日记回顾。
- 章节结束：阶段总结。

场景只是叙事包装，底层触发和证据规则一致。

## 8. AI 模块职责

### Experience Processor
整理经历、类型、授权状态和关联，不判断人格。

### Insight Analyzer
基于授权经历寻找重复行为、需求线索、认知变化和表达差异；输出带 evidence IDs 的候选观察；证据不足时返回空结果。

### Lumi Dialogue
把候选观察变成温和、克制的对话；一次优先一个问题；允许玩家纠正；不坚持自己的猜测。

### Insight Manager
管理候选观察和正式认知。正式写入必须由玩家确认动作触发。

## 9. AI 输出 schema

```ts
type InsightAnalysisResult = {
  hasInsight: boolean;
  observations: Array<{
    title: string;
    description: string;
    hypothesis: string | null;
    evidenceIds: string[];
    uncertainty: string;
    questionForPlayer: string;
  }>;
  insufficientEvidenceReason?: string;
};
```

服务端校验：
- 证据 ID 必须存在、属于当前玩家且仍授权。
- 输出字段长度和条数受限。
- 不允许诊断性结论。
- schema 不通过则安全降级。
- 模型无响应时不影响正常游戏。

## 10. 提示词基线

你是《拾己 LIFE》的人生经历观察助手。你不诊断、不评价、不贴标签，也不替玩家决定人生。你只能使用当前请求明确提供且已获授权的经历。区分玩家明确表达、客观行为、AI 观察和待确认假设。每个观察必须列出证据 ID。不得虚构经历。单次选择不足以判断人格。若证据不足，返回无观察。使用“我注意到”“这只是我的猜测”“你觉得符合吗”等表达。优先提出一个开放问题。玩家可以拒绝或纠正。不要制造羞耻、恐惧或依赖。

## 11. 隐私与授权

- 私人日记默认不进入分析上下文。
- 只向模型发送完成当前任务所需的最少经历。
- 玩家可对每条经历设置是否允许用于 AI 分析。
- 撤回授权后，该经历不得用于未来分析。
- 删除经历后，关联候选观察应标记失效或重新校验。
- 玩家可关闭 AI 分析和主动邀请。
- AI 不得跨用户检索记忆。
